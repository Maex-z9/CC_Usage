<task type="auto">
  <name>Task 2: Create API client with retry logic</name>
  <files>src/api.py, requirements.txt</files>
  <action>
1. Create `requirements.txt` with:
   ```
   requests>=2.28.0
   ```

2. Create `src/api.py` with:

   - `USAGE_ENDPOINT = "https://api.anthropic.com/api/oauth/usage"`

   - `@dataclass` class `UsageData`:
     - session_percent: float (from five_hour.utilization)
     - session_resets_at: datetime | None (from five_hour.resets_at, ISO format)
     - weekly_percent: float (from seven_day.utilization)
     - weekly_resets_at: datetime | None (from seven_day.resets_at, ISO format)

   - `class APIError(Exception)`: Base exception
   - `class AuthenticationError(APIError)`: For 401 responses
   - `class RateLimitError(APIError)`: For 429 responses, include retry_after attribute

   - `fetch_usage(access_token: str) -> UsageData`:
     - Make GET request to USAGE_ENDPOINT
     - Headers: Authorization: Bearer {token}, Accept: application/json, anthropic-beta: oauth-2025-04-20
     - On 200: parse JSON, return UsageData
     - On 401: raise AuthenticationError("OAuth token is invalid or expired")
     - On 429: raise RateLimitError with retry_after from Retry-After header (default 60s)
     - On 5xx: raise APIError(f"Server error: {status_code}")
     - On other errors: raise APIError with details

   - `fetch_with_retry(access_token: str, max_retries: int = 3) -> UsageData`:
     - Attempt fetch_usage up to max_retries times
     - On RateLimitError: wait retry_after seconds, then retry
     - On APIError (5xx, network): exponential backoff: min(30, 2^attempt) seconds
     - On AuthenticationError: do NOT retry (user action needed), re-raise immediately
     - Log each retry attempt to stderr
     - If all retries exhausted, raise the last exception

Use requests library for HTTP. Use dataclasses and datetime from stdlib.
  </action>
  <verify>
Run: `pip install -r requirements.txt && python -c "from src.api import UsageData, fetch_usage, fetch_with_retry, APIError; print('API module loads')"` succeeds.
  </verify>

  </done>
