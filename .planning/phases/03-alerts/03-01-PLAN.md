**Structure (from RESEARCH.md pattern):**
```python
from gi.repository import Notify
import subprocess
import time

class UsageNotifier:
    def __init__(self, app_name="Claude Code Usage Monitor"):
        # Initialize libnotify once
        Notify.init(app_name)
        # Track alerted thresholds: {(metric, threshold): True}
        self.alerted = {}
        # Grace period flag - skip first poll
        self.first_poll = True
        # Cache server capabilities
        self._actions_supported = None
```

**Required methods:**
1. `check_and_notify(session_pct, weekly_pct, session_reset, weekly_reset)` - Main entry point
   - Skip if first_poll (set first_poll=False and return)
   - Find highest crossed threshold for each metric (50, 75, 90)
   - Detect if session and/or weekly need alerts (not already in self.alerted)
   - Handle combined case first (both need alert), then individual cases
   - Mark thresholds as alerted after showing notification

2. `_highest_crossed(percentage, thresholds)` - Return highest threshold <= percentage, or None

3. `_show_notification(metric, percentage, threshold, reset_time)` - Single metric alert
   - Map threshold to urgency: 50→LOW, 75→NORMAL, 90→CRITICAL
   - Map threshold to advice: 50→"Heads up", 75→"Consider saving your work", 90→"Save your work now"
   - Title: "{Metric Name}: {percentage}%" (e.g., "Session Usage: 75%")
   - Body: "{advice}\n\nResets in {reset_str}"
   - Add "Open Claude Code" action button if server supports actions
   - Call notification.show()

4. `_show_combined_notification(threshold, session_pct, weekly_pct, session_reset, weekly_reset)` - Combined alert
   - Title: "Session & Weekly Usage: {threshold}%"
   - Body: "{advice}\n\nSession resets in {session_reset_str}\nWeekly resets in {weekly_reset_str}"
   - Use highest threshold's urgency when thresholds differ
   - Add action button if supported

5. `_format_reset_time(reset_timestamp)` - Format Unix timestamp to "Xh" or "Xd"
   - Handle datetime objects (use .timestamp() if needed)
   - Return "shortly" if negative or very small
   - Use divmod for hours/days calculation

6. `_server_supports_actions()` - Check if notification server supports action buttons
   - Cache result in self._actions_supported
   - Return 'actions' in Notify.get_server_caps()

7. `_on_open_claude(notification, action, user_data)` - Action button callback
   - Close notification
   - Open https://claude.ai via subprocess.Popen(["/usr/bin/xdg-open", "https://claude.ai"])

- Track separately for session vs weekly
- Grace period: skip first poll after startup
- Different thresholds in same poll → use highest urgency

**Important:** Use Notify.Urgency.LOW, Notify.Urgency.NORMAL, Notify.Urgency.CRITICAL (not string values).
