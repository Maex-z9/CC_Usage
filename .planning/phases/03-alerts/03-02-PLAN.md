**Test 1: Startup grace period**
1. Run `python -m src.main`
2. Observe: Tray icon appears, NO notification on startup (grace period working)
3. Wait for first poll refresh (up to 5 minutes) or click Refresh in menu

**Test 2: Manual threshold test**
1. Stop the app (Ctrl+C or Quit from menu)
2. Create a test script to simulate threshold crossing:
```bash
python -c "
from src.notifier import UsageNotifier
import time

notifier = UsageNotifier()
# Skip grace period
notifier.first_poll = False

# Test 75% session alert
print('Testing 75% session alert...')
notifier.check_and_notify(75, 40, time.time() + 7200, time.time() + 259200)
print('Check: notification appeared with title \"Session Usage: 75%\"')

input('Press Enter to test 90% weekly alert...')
notifier.check_and_notify(75, 90, time.time() + 7200, time.time() + 259200)
print('Check: notification appeared with title \"Weekly Usage: 90%\" and CRITICAL urgency')

input('Press Enter to test combined alert...')
# Reset alerted state for demo
notifier.alerted = {}
notifier.check_and_notify(75, 75, time.time() + 7200, time.time() + 259200)
print('Check: COMBINED notification \"Session & Weekly Usage: 75%\"')
"
```
3. Verify each notification appears with correct:
   - Title (metric name + percentage)
   - Body (advice + reset time)
   - Urgency (visual prominence for CRITICAL)
   - Action button (if your GNOME supports it)

**Test 3: No re-alert**
1. Continue from Test 2 — try triggering 75% session again
2. Observe: No new notification (already alerted)
