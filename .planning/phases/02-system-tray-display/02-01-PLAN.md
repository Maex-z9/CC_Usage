<task type="auto">
  <name>Task 1: Create icon generator module with Cairo</name>
  <files>src/icon_generator.py</files>
  <action>
Create src/icon_generator.py with:

1. **get_color_for_percentage(percentage: float) -> tuple[float, float, float]**
   - Returns RGB tuple in Cairo format (0.0-1.0 range)
   - Green (0.2, 0.8, 0.2) for percentage < 50
   - Yellow (0.9, 0.7, 0.0) for 50 <= percentage < 75
   - Red (0.9, 0.2, 0.2) for percentage >= 75
   - These thresholds are sensible defaults (Claude's discretion per CONTEXT.md)

2. **generate_gauge_icon(percentage: float, color_percentage: float, size: int = 22) -> str**
   - Creates circular gauge icon using Cairo
   - Returns absolute path to generated PNG in /tmp
   - **IMPORTANT: percentage controls the arc fill amount (how full the gauge is)**
   - **IMPORTANT: color_percentage controls the color (via get_color_for_percentage)**
   - This separation allows showing session usage (arc) while coloring by worst-case urgency
   - Arc starts at 12 o'clock (-math.pi/2 radians) and goes clockwise
   - Gray outline: RGB (0.5, 0.5, 0.5)
   - Colored fill uses get_color_for_percentage(color_percentage)
   - Use unique filename per color state to bust icon cache: /tmp/claude-usage-{color}.png
   - Leave 2px margin around edge for clean rendering

Implementation notes:
- Use cairo.ImageSurface(FORMAT_ARGB32, size, size) for transparent background
- Line width of 2px for both outline and fill arc
- Clear background with transparent color before drawing
- Call surface.write_to_png() to save
- Return os.path.abspath() of the generated file
  </action>

Expected: Prints green color tuple, yellow color tuple, red color tuple, icon path (showing 30% fill but red color since color_percentage=80), and Exists: True
  </verify>
