**Class: TrayIndicator**

1. **__init__(self)**
   - Store APPINDICATOR_ID = 'claude-usage-overlay'
   - Initialize self.usage_data = None (will hold UsageData)
   - Initialize self.indicator = None
   - Initialize self.menu = None
   - Call self._setup_indicator()
   - Call self._update_usage() for initial data
   - Start periodic updates with GLib.timeout_add_seconds(300, self._update_usage) (5 min)

2. **_setup_indicator(self)**
   - Create initial icon at 0% fill with 0% color (both green, empty gauge)
   - Create AppIndicator3.Indicator.new(APPINDICATOR_ID, icon_path, IndicatorCategory.APPLICATION_STATUS)
   - Set status to ACTIVE
   - Build initial menu with "Loading..." text
   - Call menu.show_all() and indicator.set_menu(menu)

3. **_update_usage(self) -> bool**
   - Try to fetch usage data:
     - from src.config import get_access_token
     - from src.api import fetch_with_retry
     - token = get_access_token()
     - self.usage_data = fetch_with_retry(token)
   - On success: call self._refresh_display()
   - On error: print to stderr, set tooltip to error message
   - Return GLib.SOURCE_CONTINUE (keeps timer running)

4. **_refresh_display(self)**
   - If no usage_data, return
   - Get session_percent from usage_data.session_percent
   - Get weekly_percent from usage_data.weekly_percent
   - **IMPORTANT: Separate concerns per CONTEXT.md decisions:**
     - **Arc fill (percentage parameter) = session_percent** (shows 5-hour usage level)
     - **Color (color_percentage parameter) = max(session_percent, weekly_percent)** (worst-case urgency)
   - Generate icon: generate_gauge_icon(session_percent, max(session_percent, weekly_percent))
   - Update icon with indicator.set_icon_full(icon_path, 'Claude usage gauge')
   - Update tooltip: indicator.set_title(f"Session: {session_percent:.0f}% | Weekly: {weekly_percent:.0f}%")
   - Rebuild menu with _build_menu()

5. **_build_menu(self) -> Gtk.Menu**
   - Create Gtk.Menu()
   - Add usage line (non-clickable): "Session: {X}%  |  Weekly: {Y}%" using .set_sensitive(False)
     - Format as whole numbers (:.0f) per CONTEXT.md
   - Add reset time line (non-clickable): "Resets in {time}" using format_time_until()
     - Use session_resets_at (5-hour is the more relevant one for active users)
   - Add Gtk.SeparatorMenuItem()
   - Add "Refresh" item with connect('activate', self._on_refresh_clicked)
   - Add "Settings" item with set_sensitive(False) (placeholder for Phase 4)
   - Add Gtk.SeparatorMenuItem()
   - Add "Quit" item with connect('activate', self._on_quit_clicked)
   - Call menu.show_all()
   - Set self.menu = menu and indicator.set_menu(menu)
   - Return menu

6. **_on_refresh_clicked(self, widget)**
   - Call self._update_usage()

7. **_on_quit_clicked(self, widget)**
   - Call Gtk.main_quit()

8. **run(self)**
   - Call Gtk.main()

Create src/main.py as the application entry point:

```python
#!/usr/bin/env python3
"""Claude Code Usage Overlay - System tray application."""

import sys

def main():
    """Start the Claude Code Usage Overlay application."""
    try:
        from src.tray import TrayIndicator

        indicator = TrayIndicator()
        indicator.run()

    except KeyboardInterrupt:
        print("\nShutting down...")
        sys.exit(0)
    except Exception as e:
        print(f"Fatal error: {e}", file=sys.stderr)
        sys.exit(1)

if __name__ == "__main__":
    main()
```
