Extend src/config.py (keep existing OAuth functions) with:

1. Add imports at top: `from dataclasses import dataclass, asdict`

2. Add `get_config_path()` function:
   - Check `os.environ.get('XDG_CONFIG_HOME')` first
   - Fall back to `Path.home() / '.config'`
   - Return `base / 'claude-usage-overlay' / 'config.json'`
   - Create parent directories if needed (`mkdir(parents=True, exist_ok=True)`)

3. Create `@dataclass` class `UserConfig`:
   - `session_thresholds: list[int] = None` (default [50, 75, 90] in __post_init__)
   - `weekly_thresholds: list[int] = None` (default [50, 75, 90] in __post_init__)
   - `polling_interval: int = 300` (seconds, 5 min default)
   - `pause_notifications: bool = False`
   - `autostart_enabled: bool = False`

4. Implement `__post_init__` validation:
   - Set defaults for None fields (mutable default trap avoidance)
   - Validate thresholds are integers 0-100
   - Validate polling_interval is integer 30-3600
   - Validate pause_notifications and autostart_enabled are bool
   - Raise ValueError with clear message on invalid values

5. Add `@classmethod load(cls) -> 'UserConfig'`:
   - Get path from get_config_path()
   - If file doesn't exist, return cls() (defaults)
   - Try json.load + cls(**data)
   - On json.JSONDecodeError: raise ValueError with message
   - On TypeError: raise ValueError with message

6. Add `save(self)` method:
   - Get path from get_config_path()
   - Ensure parent dir exists
   - json.dump(asdict(self), f, indent=2)

<task type="auto">
  <name>Task 2: Create autostart.py with .desktop file management</name>
  <files>src/autostart.py</files>
  <action>
Create new file src/autostart.py with:

1. Imports: `os`, `from pathlib import Path`

2. `get_autostart_path() -> Path`:
   - Check `os.environ.get('XDG_CONFIG_HOME')` first
   - Fall back to `Path.home() / '.config'`
   - Return `base / 'autostart'`
   - Create dir if needed

3. `get_desktop_file_path() -> Path`:
   - Return `get_autostart_path() / 'claude-usage-overlay.desktop'`

4. `create_autostart_entry(enable: bool = True)`:
   - Get desktop file path
   - Get absolute path to main.py:
     ```python
     project_root = Path(__file__).parent.parent.absolute()
     exec_path = f"/usr/bin/python3 {project_root}/src/main.py"
     ```
   - Write .desktop file content:
     ```
     [Desktop Entry]
     Type=Application
     Version=1.0
     Name=Claude Code Usage Monitor
     Comment=System tray monitor for Claude Code token usage
     Exec={exec_path}
     Icon=dialog-information
     Terminal=false
     Categories=Utility;Monitor;
     StartupNotify=false
     X-GNOME-Autostart-enabled=true
     Hidden={false if enable else true}
     ```
   - Make file executable: `chmod(0o755)`

5. `remove_autostart_entry()`:
   - Get desktop file path
   - If exists: unlink()

6. `is_autostart_enabled() -> bool`:
   - Get desktop file path
   - If not exists: return False
   - Read file content
   - Parse for `Hidden=true` line (case insensitive value)
   - Return True if Hidden not present or Hidden=false
  </action>
